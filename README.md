# Генератор авансового отчёта (форма АО-1)

Веб-приложение для быстрого заполнения формы АО-1 на основе данных чеков.

## Что делает

1. Запрашивает у пользователя общие данные (ФИО, дата, должность, подразделение, сумма аванса)
2. Позволяет добавить один или несколько чеков/документов
3. Заполняет шаблон `avanschek.xls` через Microsoft Excel (сохраняется точное форматирование)
4. Генерирует готовый PDF для печати

## Требования

- Windows с установленным Microsoft Excel
- Python 3.x
- Зависимости: `flask`, `pywin32`

## Установка

```bash
pip install flask pywin32
```

Или просто запустите `start.bat` — зависимости уже должны быть установлены.

## Запуск

### Через batch-файл
Дважды кликните `start.bat`

### Вручную
```bash
python app.py
```

После запуска откройте в браузере: **http://localhost:5000**

### Доступ с телефона
Если компьютер и телефон подключены к одной Wi-Fi сети, откройте на телефоне адрес, который покажет консоль при запуске (например, `http://192.168.1.132:5000`).

## Как пользоваться

### Ручной ввод
1. Заполните общие данные в верхней части формы
2. Нажмите "+ Добавить чек" и введите данные с чека:
   - Дата документа (в формате ДД/ММ)
   - Номер чека
   - Наименование покупки / назначение платежа
   - Сумма
   - Дебет счёта (по умолчанию "Студия")
   - Можно прикрепить фото чека для себя (не обязательно)
3. При необходимости добавьте ещё чеки
4. Нажмите "Сгенерировать документы"
5. Скачайте готовый Excel (.xls) и PDF

### Распознавание QR-кода с фотографии
В каждой карточке чека есть кнопка **"📷 Загрузить фото с QR-кодом"**:
1. Сфотографируйте чек (или сохраните скриншот) — главное, чтобы был виден QR-код
2. Нажмите кнопку и выберите фото
3. Программа автоматически извлечёт:
   - **Дату** чека
   - **Сумму**
   - **Номер документа** (фискальный документ / фискальный признак)
4. Допишите наименование покупки вручную и нажмите "Сгенерировать документы"

### Получение полных данных из ФНС (список товаров, НДС, магазин)
1. Зарегистрируйтесь на [proverkacheka.com](https://proverkacheka.com/) и получите бесплатный API-токен (~15 чеков/сутки)
2. Вставьте токен в поле "Токен proverkacheka.com" в верхней части формы
3. При загрузке фото с QR-кодом программа автоматически:
   - Получит из базы ФНС **полный список товаров** и заполнит наименование
   - Подтянет **название магазина** (добавит к номеру документа)
   - Уточнит сумму и дату из ФНС

> **Без токена:** распознаётся только дата, сумма и номер документа из QR-кода. Наименование товара нужно вписать руками.
> **С токеном:** автоматически заполняется полное наименование покупки (все товары через запятую) + магазин.

Готовые файлы сохраняются в папку `output/`.

├── static/

## Важно

- Файл `avanschek.xls` — это шаблон. Не редактируйте его напрямую в Excel, если хотите сохранить исходное форматирование.
- Для корректной работы PDF-экспорта на компьютере должен быть установлен Microsoft Excel.
- Если Excel не установлен, приложение не сможет сгенерировать документы.
