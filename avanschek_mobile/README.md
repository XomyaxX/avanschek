# Авансовый отчёт — Мобильное приложение (Flutter)

Нативное Flutter-приложение для создания авансовых отчётов формы АО-1.

## Функции

- 📋 Заполнение общих данных (ФИО, дата, должность, подразделение, аванс)
- 🧾 Добавление нескольких чеков/документов с live подсчётом остатка/перерасхода
- 📷 **Сканирование QR-кода камерой телефона** (через `mobile_scanner`) — локально
- 🖼️ **Загрузка фото чека из галереи** с локальным распознаванием QR
- 📄 **Генерация XLSX строго по официальному шаблону АО-1** (архивный патч ячеек по точным A1-адресам) + **PDF как буквальная конверсия xlsx→html-таблица-сетка (с colspan/rowspan + бордеры из стилей шаблона) → PDF** — всё полностью локально на телефоне. PDF теперь визуально копия того, что дал бы печать xlsx в Excel (по ГОСТ, без ручной реконструкции).
- 📥 Скачивание и отправка готовых документов (XLSX + PDF)
- 🕘 **История отчётов** — сохранение всех сгенерированных отчётов в локальной базе данных
- 💾 **Автосохранение черновиков** — при закрытии приложения несохранённые данные восстанавливаются при следующем запуске

## Архитектура

Генерация документов (XLSX по точному шаблону + PDF) выполняется **полностью на устройстве** без `excel` пакета (используется низкоуровневый archive + ручная правка sheet1.xml для сохранения всех 457+ мержей, стилей, границ, printSetup). PDF делается через парсинг готового xlsx в HTML-реплику таблицы (ячейки + sharedStrings + merges + col widths + selective borders из styles.xml) + flutter_html_to_pdf_plus (A4, margins по template, page-break по rowBreak=56). 

Нет необходимости в сервере Flask / Excel COM для создания отчёта. Сервер (опционально) может использоваться только для расширенного получения данных чека по токену proverkacheka.com.

## Требования для сборки

1. **Flutter SDK** — https://docs.flutter.dev/get-started/install
2. **Android Studio** — устанавливает JDK + Android SDK + Gradle автоматически
3. **Developer Mode** в Windows — нужен Flutter для работы с плагинами:
   - Настройки → Конфиденциальность и безопасность → Для разработчиков → Режим разработчика → Вкл.

## Настройка (опционально) для расширенных функций

Для опциональной загрузки полных данных чека (магазин, товары) из ФНС создайте/измените `assets/.env`:

```env
API_BASE_URL=http://192.168.1.132:5000
```

(Требуется запущенный сервер Flask с поддержкой /fetch_receipt. Основная генерация отчёта работает без него.)

> **Важно:** файл `assets/.env` добавлен в `.gitignore` и не попадёт в репозиторий.

## Сборка APK (Android)

```bash
cd C:\avanschek_mobile
flutter build apk --release
```

Готовый APK будет в:
```
build\app\outputs\flutter-apk\app-release.apk
```

## Обновление приложения изнутри (кнопка в меню)

В главном экране (три точки → «Обновить приложение») реализовано:

- Проверка версии через сервер (`/check_update`).
- Скачивание APK с прогрессом.
- Запрос разрешения `REQUEST_INSTALL_PACKAGES`.
- Запуск системного установщика.

**Контракт сервера (GET /check_update):**
```json
{
  "version": "1.0.1",
  "build_number": "2",
  "apk_url": "/downloads/avanschek-1.0.1.apk",
  "changelog": "Исправления..."
}
```

Разместите собранный APK на своём сервере (по пути из `apk_url`) и реализуйте эндпоинт, возвращающий JSON выше. Относительные URL дополняются `API_BASE_URL`.

```
├── models/
│   ├── check.dart               # Модель чека

├── services/
│   ├── api_service.dart         # HTTP-клиент для Flask API
│   ├── db_service.dart          # Локальная SQLite база данных
│   └── prefs_service.dart       # SharedPreferences wrapper

    ├── onboarding_screen.dart   # Инструкция для новых пользователей
    └── profile_setup_screen.dart # Первоначальная настройка профиля
```

## Получение токена API ФНС

1. Зарегистрируйтесь на https://proverkacheka.com/
2. В профиле нажмите «Сгенерировать» рядом с полем токена
3. Вставьте токен в поле «Токен proverkacheka.com» в приложении

Бесплатный лимит: ~15 чеков в сутки.
